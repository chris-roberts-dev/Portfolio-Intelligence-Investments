## 8. Actual-portfolio comparison semantics

The Rebalancing Lab distinguishes:

- actual account start/end values;
- canonical actual-portfolio same-period TWR;
- hypothetical policy values and returns;
- normalized growth-of-$100 presentation;
- percentage-point policy difference versus actual.

The authoritative percentage-point calculation remains backend-owned:

```text
policy cumulative return - actual portfolio same-period TWR
```

Reference fixture:

```text
Actual portfolio:   60.40%
Annual rebalance:   69.52%
Difference:         +9.12 pp
```

The frontend formats and presents these values but does not recalculate authoritative return, drift, turnover, costs, trade quantities, or percentage-point differences.
